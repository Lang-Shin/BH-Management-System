# Brand fonts

Self-hosted Latin WOFF2 files from Google Fonts:

- Luckiest Guy, normal 400 (Halili BH): https://fonts.google.com/specimen/Luckiest+Guy
- Tiny5 Duo, normal 400: https://fonts.google.com/specimen/Tiny5+Duo
- Lilita One, normal 400 (tomato surfaces): https://fonts.google.com/specimen/Lilita+One

Original license texts are included alongside the files. These fonts are used for the Halili BH / BHMS identity and tomato-red containers; other application content continues to use Nunito.

The earlier Anton asset and its license are retained but are no longer referenced by the application.
